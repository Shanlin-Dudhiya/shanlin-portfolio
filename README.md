# Shanlin Dudhiya — Portfolio

Personal portfolio site built from my resume, showcasing my experience,
skills, and projects as a Full Stack Developer.

## Tech stack

React (Vite), Tailwind CSS.

## Sections

- Hero / About / Skills
- Work Experience
- Projects — [Bookworm](https://github.com/Shanlin-Dudhiya/Bookworm),
  [LR Photo Presets Platform](https://github.com/Shanlin-Dudhiya/lr-photo-presets),
  [Bulk Mail Sender](https://github.com/Shanlin-Dudhiya/mailer)
- Education
- Contact (email, WhatsApp, LinkedIn, GitHub)

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
